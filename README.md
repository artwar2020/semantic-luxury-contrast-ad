# Semantic Luxury Contrast Ad (反差奢侈化概念广告)

> 🕶️ **普通物件 × 顶级品类广告语法 × 一本正经的哲学化解释 × 明显但不点破的荒诞 = 高级反差概念片**
> 
> 将廉价、日常、普通甚至“土”的物件，通过高端广告语法、语义错位、电影化景观、冷面表演与哲学化文案，重构为具有奢侈品/汽车/时装大片气质的概念短片。专为生成创意概念、脚本、分镜、AI视频提示词（Kling / Seedance / MiniMax / Runway）、旁白字幕与声音设计而设计。

## 🎯 核心定义

这个方法不是“把普通产品拍漂亮”，也不是“恶搞奢侈品”。

它的核心是：

> **让一个极普通的对象，暂时获得一种远高于其现实身份的文化语法；全片一本正经地维持这种语法，直到观众主动发现两者之间的巨大错位。**

真正的笑点与记忆点来自 **身份落差 + 语义自洽**，而不是演员做鬼脸、网络梗堆砌或突然反转。

## 🧬 三大底层机制

### 1. 语义升维（Semantic Elevation）
先找到物件最朴素的物理功能，再把这个功能升维为更高级的抽象命题：
`物理功能 → 人的行为 → 人生动作 → 抽象命题`

- **“坐”** → 位置 / 选择 / 立场 / 停留
- **“走”** → 出发 / 自由 / 方向 / 边界
- **“装东西”** → 容纳 / 秩序 / 私人空间
- **“遮雨”** → 边界 / 保护 / 与天气相处
- **“便宜耐用”** → 去掉装饰后的本质 / 不需要被证明

*例：凳子让人坐下 → 选择坐在哪里 → 选择自己的位置 → “位置不是被安排的，是自己坐出来的。”*

### 2. 品类借壳（Category Borrowing）
整个短片只选择 **1 个主借壳品类**（最多加 1 个辅助品类），借壳品类必须与原物件至少共享一个真实属性：
- **普通鞋类** → 马术 / 奢侈时装 / 自由精神（共享：脚、行走、自由姿态）
- **塑料凳** → 家具设计 / 建筑 / 当代艺术装置（共享：坐、结构、位置、空间）
- **三轮车** → 豪华汽车 / 公路电影 / 探险品牌（共享：轮、路、驾驶、风）
- **塑料袋** → 高级时装 / 空气与流动（共享：包裹、轻盈、流动）
- **电饭煲** → 精密机械 / 建筑 / 私人仪式（共享：温度、时间、内部空间）
- **蚊香** → 香氛 / 天文 / 东方仪式（共享：烟、气味、时间流逝）

### 3. 冷面荒诞（Deadpan Absurdity）
**所有人都必须相信眼前发生的一切是正常的：**
- **演员**：不眨眼式搞笑、不做“我知道这很荒谬”的表情，态度像时装大片与汽车广告般克制冷峻。
- **镜头**：不用喜剧推拉镜头提醒观众笑，不用搞笑音效，让荒诞被高规格摄影严肃地记录下来。
- **金句原则**：*越认真，越好笑；越解释，越不好笑。对象掉下来了，摄影不能掉下来。*

## 🎬 8 Beat 故事结构（90–150秒成片骨架）

| 节拍 | 时长占比 | 核心任务 | 视听策略 |
| :--- | :--- | :--- | :--- |
| **Beat 1** | 0–8% | 建立“错误期待” | 极远景、航拍、抽象微距，让观众误以为在看顶奢大片 |
| **Beat 2** | 8–18% | 提出过度认真的命题 | 探讨自由、距离、秩序、位置，与功能暗中相关但不点破 |
| **Beat 3** | 18–32% | 第一次给产品线索 | 局部、轮廓、材质、声音，像艺术品一样对待物件 |
| **Beat 4** | 32–48% | 人物进入与同框 | 人物是世界观居民（同色系/高级西装/荒野错位） |
| **Beat 5** | 48–66% | 第一次明确荒诞 | 观众看清普通物件，但高规格摄影与庄严感毫不动摇 |
| **Beat 6** | 66–82% | 普通功能命名为“高级特性” | 敞篷=全方位自然通风，耐摔=无惧环境变化，逻辑闭环 |
| **Beat 7** | 82–94% | 情绪升高，升维精神符号 | 大空间、音乐展开、镜头拉远，把功能升华到生活态度 |
| **Beat 8** | 94–100% | 一句收束 + 终极 Hero Shot | 既像品牌宣言又能回扣物件，不解释笑点，海报级定格 |

## 🎥 AI 视频生成提示词规范

### 1. 通用提示词骨架
```text
电影化商业短片，一个[人物]在[环境]中与[普通物件]发生极自然的互动。
整个世界把这个物件当作高端设计对象看待。画面克制、严肃、无喜剧表演。
[景别]，[镜头运动]，自然光，[时间/天气]，真实材质，轻微胶片颗粒，
低至中饱和环境色，[产品锚点色]作为唯一强色。人物表情冷静、自洽，不看镜头，不解释。
真实重力、真实接触、真实风与衣料反应。16:9，24fps，电影广告质感。
```

### 2. 通用负面约束
```text
避免短视频网红感、避免夸张搞笑表情、避免卡通、避免过度赛博、避免廉价霓虹、
避免塑料皮肤、避免产品变形、避免多余手指、避免文字乱码、避免镜头无理由快速晃动、
避免每镜都正面展示产品、避免浮夸 VFX、避免电商棚拍。
```

## 📋 10 项严苛质量门禁

在成片与分镜交付前，系统执行 10 项一票否决式自检：

1. [x] **普通物件真实身份**：未被爆改成真正奢侈品，保留真实质感与生活痕迹；
2. [x] **借壳品类单一明确**：主品类仅限 1 个，不杂糅；
3. [x] **真实共享语义**：原物件与借壳品类存在无法辩驳的物理/文化重叠点；
4. [x] **前 20% 错误期待**：前 1/5 成功诱导观众以为是高端广告；
5. [x] **荒诞完整露出**：至少有一次高清、体面的完整全景；
6. [x] **文案追溯到功能**：60% 以上文案非空话，能倒推回物理属性；
7. [x] **冷面自洽表演**：无演员会心一笑，全员严肃真诚；
8. [x] **高规格摄影锁死**：荒诞曝光后，摄影质量与构图绝不掉价；
9. [x] **海报级 Hero Shot**：片尾留白充足、稳定大气的终局定格；
10. [x] **终局宣言双关回扣**：最后一句文案单读是格言，对照物件是妙笔。
